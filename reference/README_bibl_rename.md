# Bibl-Rename

Система управления библиотекой научной литературы с автоматическим переименованием файлов по библиографическому списку.

## Возможности

- **Автоматическое сопоставление** файлов с библиографией
- **Умное переименование** с указанием типа документа, авторов и сокращённым заголовком
- **Определение типа работы** — статья, книга, диссертация, монография, конференция, сборник, отчёт, стандарт, патент
- **Несколько авторов** — до 3 фамилий в имени файла; при большем числе — `Иванов_и_др` / `Smith_et_al`
- **Сокращение заголовков** — длинные слова заменяются аббревиатурами (например, `электроэнергетики` → `электроэнерг.`)
- **Конвертация в ГОСТ Р 7.0.100-2018** с полным форматированием
- **Web-интерфейс** для визуальной работы (FastAPI + HTMX)
- **CLI-интерфейс** с режимами match, gost, stats, export, web, init
- **Отчёты** и экспорт в JSON/Markdown
- **Ручное сопоставление** через JSON-файл для сложных случаев

## Установка

```bash
# Клонировать репозиторий
cd bibl-rename

# Установить зависимости через UV
uv sync
```

## Быстрый старт

```bash
# Создать конфигурацию
python -m src init

# Запустить веб-интерфейс
python -m src web

# Или использовать CLI
python -m src match -s ./literature_files -o ./renamed_literature

# Конвертировать в ГОСТ
python -m src gost -i dissertation_bibliography.txt -o bibliography_gost.txt

# Показать статистику
python -m src stats

# Экспортировать библиографию
python -m src export -f json
```

## Команды CLI

| Команда | Описание |
|---------|----------|
| `match` | Сопоставить и переименовать файлы |
| `gost` | Конвертировать в формат ГОСТ |
| `stats` | Показать статистику библиотеки |
| `export` | Экспортировать библиографию (json/markdown/gost) |
| `web` | Запустить веб-интерфейс |
| `init` | Создать конфигурационный файл |

## Опции match

```
-s, --source       Папка с исходными файлами (по умолчанию: ./literature_files)
-o, --output       Папка для результатов (по умолчанию: ./renamed_literature)
-b, --bibliography Файл библиографии (по умолчанию: dissertation_bibliography.txt)
-t, --threshold    Порог уверенности 0-1 (по умолчанию: 0.30)
--json             Сохранить отчёт в JSON
--dry-run          Показать новые имена без копирования
```

## Web-интерфейс

После запуска `python -m src web` откройте http://localhost:8000

Страницы:
- `/` — Дашборд (статистика библиотеки)
- `/bibliography` — Редактирование библиографии
- `/matching` — Сопоставление файлов
- `/rename` — Настройка шаблонов и запуск переименования
- `/reports` — Отчёты и экспорт

## Конфигурация

Создайте `config.json` (или используйте `python -m src init`):

```json
{
  "mode": "match",
  "source": "./literature_files",
  "output": "./renamed_literature",
  "bibliography": "dissertation_bibliography.txt",
  "naming": {
    "template": "{index:02d}_{type}_{authors}_{title}",
    "include_type": true,
    "max_title_len": 50,
    "max_authors": 3
  },
  "matching": {
    "threshold": 0.30,
    "manual_matching_file": null
  }
}
```

## Типы документов

Система автоматически определяет тип:
- `article` — статья
- `book` — книга
- `dissertation` — диссертация
- `monograph` — монография
- `conference` — конференция
- `collection` — сборник
- `report` — отчёт
- `standard` — стандарт
- `patent` — патент

## Формирование имён файлов

Шаблон по умолчанию: `{index:02d}_{type}_{authors}_{title}.pdf`

```
01_диссертация_Иванов_и_др_исслед._феррорез._в_электр._цепях.pdf
05_статья_Петров_АС_Анализ_изоляции_трансформаторов.pdf
12_монография_Сидоров_ВН_Электрооборудование_высокого_напряжения.pdf
128_отчёт_Лебедев_и_др_мультифункционал_систем._на_основ._цифров._трансф._тока.pdf
```

### Правила сокращения заголовков
- Слова до 5 символов — без изменений
- Слова 6-10 символов — до 4 символов
- Слова длиннее 10 символов — до 6 символов
- Используются словарные сокращения для типовых суффиксов:
  - `изирование` → `изир.`, `ический` → `ич.`, `ование` → `ов.` и т.д.

### Форматирование авторов
- 1 автор: `Иванов`
- 2-3 автора: `Иванов_Петров_Сидоров`
- 4+ авторов: `Иванов_и_др` (для русских) / `Smith_et_al` (для английских)

## Реализованные улучшения

- Извлечение DOI, ISBN, URL, года, страниц из записи
- Автоопределение типа документа по ключевым словам
- Поддержка кириллицы и латиницы в авторах и заголовках
- Дефисные фамилии (Сержаский-Серж)
- Ручные сопоставления через JSON
- Dry-run режим для предпросмотра
- Партитивный импорт из PDF, DOCX, TXT, DJVU
- Нормализация множественных подчёркиваний
- Удаление `и.д.` из заголовков
- Фикс года: выбор последнего `\d{4}` (год публикации в конце записи)
