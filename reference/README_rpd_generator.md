# PDF → DOCX Конвертер

CLI-инструмент для пакетной конвертации PDF файлов в DOCX с поддержкой различных бэкендов и сохранением структуры папок.

## Требования

1. **Python 3.10+** (управляется через `uv`)
2. **Опционально: LibreOffice** (только для инструмента `libreoffice`)

## Установка

```bash
# Установите зависимости через uv
uv sync
```

## Доступные инструменты конвертации

| Инструмент | Описание | Требования |
|------------|----------|------------|
| `libreoffice` | Конвертация через LibreOffice (двухэтапная: PDF→ODT→DOCX) | Установленный LibreOffice |
| `pdf2docx` | Конвертация через Python-библиотеку pdf2docx | Только Python-зависимости |
| `pymupdf` | Конвертация через PyMuPDF (fitz) с базовым форматированием | Только Python-зависимости |

## Использование

### Базовая конвертация (LibreOffice по умолчанию)

```bash
uv run python pdf_to_docx.py -i "РПД и ФОС\2025" -o converted
```

### Конвертация с выбором инструмента

```bash
# Через pdf2docx
uv run python pdf_to_docx.py -i "РПД и ФОС\2025" -o converted --tool pdf2docx

# Через PyMuPDF
uv run python pdf_to_docx.py -i "РПД и ФОС\2025" -o converted --tool pymupdf

# Через LibreOffice (явно)
uv run python pdf_to_docx.py -i "РПД и ФОС\2025" -o converted --tool libreoffice
```

### Конвертация конкретной папки

```bash
uv run python pdf_to_docx.py -i "РПД и ФОС\2025\заочная\1 курс" --tool pdf2docx -o result
```

### Dry-run (показать файлы без конвертации)

```bash
uv run python pdf_to_docx.py -i "РПД и ФОС\2025" --dry-run
```

### Если LibreOffice не в PATH

```bash
uv run python pdf_to_docx.py -i "РПД и ФОС\2025" --tool libreoffice --libreoffice-path "C:\Program Files\LibreOffice\program\soffice.exe"
```

## Параметры

| Параметр | Описание |
|----------|----------|
| `-i, --input` | Путь к директории с PDF (обязательно) |
| `-o, --output` | Путь к выходной директории (по умолчанию: `converted_docx`) |
| `--tool` | Инструмент конвертации: `libreoffice`, `pdf2docx`, `pymupdf` (по умолчанию: `libreoffice`) |
| `--libreoffice-path` | Путь к `soffice.exe` (только для `libreoffice`) |
| `--dry-run` | Показать файлы для конвертации без выполнения |

## Структура выходных файлов

Инструмент сохраняет исходную структуру папок:

```
РПД и ФОС\2025\заочная\1 курс\OOP_13.03.02_02_Z_1.pdf
                                    ↓
converted_docx\РПД и ФОС\2025\заочная\1 курс\OOP_13.03.02_02_Z_1.docx
```

## Сравнение инструментов

### LibreOffice
- ✅ Лучшее сохранение форматирования
- ✅ Поддержка сложных элементов (таблицы, формулы)
- ❌ Требует установки LibreOffice
- ❌ Медленнее (2-5 сек/файл)

### pdf2docx
- ✅ Не требует внешних зависимостей
- ✅ Отличное сохранение структуры и форматирования
- ✅ Сохраняет таблицы, изображения, верстку
- ⚠️ Медленнее на больших файлах (10-30 сек/файл)
- ⚠️ Файлы большего размера

### PyMuPDF (fitz)
- ✅ Не требует внешних зависимостей
- ✅ Самый быстрый (~2 сек/файл)
- ✅ Маленький размер выходных файлов
- ❌ Базовое форматирование (только текст)
- ❌ Не сохраняет таблицы и сложную верстку

## Результаты тестов

| Инструмент | Скорость | Размер выхода | Качество |
|------------|----------|---------------|----------|
| `pdf2docx` | ~10-30 сек/файл | 567 КБ (16 стр.) | Отличное |
| `pymupdf` | ~2 сек/файл | 50 КБ (16 стр.) | Базовое |
| `libreoffice` | ~3-5 сек/файл | Зависит от файла | Хорошее |

## Примечания

- Все инструменты работают в headless-режиме
- Сложные элементы (таблицы, формулы) могут требовать ручной проверки
- Для наилучшего качества используйте `libreoffice`
- Для скорости без сложного форматирования — `pymupdf` или `pdf2docx`
