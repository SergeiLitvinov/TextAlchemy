# PDF: остаток приёмки интерактивных объектов и маленькой страницы

Владелец чтения/экспорта — OpenDoc Formats. Проверено на официальном 0.10.0 и OpenDoc Model 0.3.0, TextAlchemy 0.2.0rc2. Приложение принимает готовые API и не изменяет библиотеку.

## Принятая область импорта

Собственный `tests/corpus/pdf_interactions.py` содержит URI-link, note, highlight и текстовое поле со значением `Initial`. Два Web-повтора JSON сохраняют typed integration, значения, инертное действие поля, координаты, provenance и байты исходного PDF. Вариант rotation 90 сохраняет пространство координат `pymupdf-unrotated` и признак поворота. Неподдержанная прямоугольная аннотация и outline дают расположенную диагностику и непрозрачное сохранение.

## Остаток экспорта

PDF layout writer не создаёт annotations/forms/outline в PDF-результате. Это диагностируется как LOSS; нулевой бюджет TextAlchemy отклоняет публикацию и сохраняет прежний файл. Разрешающий экспорт даёт плоский результат без нативных ссылок/аннотаций/widgets. Следующий импорт такого файла не восстанавливает исходную интерактивность.

Предлагаемая библиотечная приёмка: выбранная typed annotation/form либо восстанавливается с конкретно объявленной областью поведения/геометрии, либо имеет адресную диагностику утраты; исходные данные, отказ и ограничения сохраняются. Инертное действие в модели не следует автоматически исполнять. Реальная правка/повторное открытие в целевом PDF viewer остаются отдельной приёмкой, не выводом из состояния `semantic` импорта.

## Маленькая страница

Вариант fixture `small=True` имеет страницу 240×200 pt. После PDF → модель → PDF нормализованный полный текст страницы не совпадает с исходником. Наблюдалась обрезка заголовка или исчезновение отображаемого значения поля в зависимости от подстановки шрифта; не утверждается единственный потерянный фрагмент. Отдельного сообщения о текстовой обрезке нет. `tests/test_web_pdf_interactions.py::test_small_pdf_known_text_clipping_is_not_called_preserved` воспроизводит несовпадение и проверяет отказ `text_preservation=flow,max_text_edits=0`. Успех этого теста фиксирует известный дефект, а не принятую сохранность текста.

Ожидаемый контракт: доступная область страницы/поля и текст согласованы либо диагностирована невозможность сохранить содержимое. Проверка включает реальное извлечение текста из результата, отказ с сохранением прежнего файла и повторный цикл. Минимальный случай полностью собственный; документы пользователя не публикуются. Исправление должно поступить отдельным выпуском библиотеки.

## Конечный повтор закладок на 0.18.0

Общий Outline уже записывается в PDF: собственные два цикла с нативной правкой сохраняют названия, иерархию, страницы, zoom и точки перехода на обрезанных страницах с поворотами 0/90/180/270°. Явное удаление не восстанавливает прежнее оглавление. Неподдержанный переход даёт расположенный отказ по бюджету с сохранением прежнего файла. Прежнее утверждение о полном отсутствии экспорта outline относится к 0.10.0; аннотации/формы, полные actions, непрозрачные свойства и маленькая страница остаются отдельными остатками. [Область приёмки](../../guide/verification.md#pdf-закладки-0180).
