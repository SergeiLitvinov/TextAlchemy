# Контракт OpenDoc Model для отдельной сессии

Владелец — [OpenDoc Model](https://github.com/SergeiLitvinov/opendoc-model). Дистрибутив — `opendoc-model`, импорт — `opendoc_model`; подключён официальный выпуск 0.7.2 вместе с OpenDoc Formats 0.18.0, требующим ровно эту версию модели. Переименование согласовано в приложении; новых библиотечных требований оно не создаёт.
Аудит 2026-10-04 не обнаружил подтверждённого пробела модели для сохранения текущих функций.
Активных запросов нет. Это передача требований, а не разрешение менять библиотеку здесь.

## Контракт будущего запроса

OD-NN содержит версию, вызывающий код, разрешённый fixture и происхождение, вход,
ожидаемую модель/JSON, публичную сигнатуру/результат, диагностику, лимиты/отмену,
совместимость прежних JSON и приёмку. Новые поля имеют правила чтения, валидации и сравнения.
Отсутствие измерений не заменяется нулём. Не создавать структуры без воспроизводимого случая.

Сначала пользователь реализует потребность в отдельной библиотечной сессии и выпускает версию.
Затем приложение подключает неизменённый wheel с SHA-256 и проверяет интеграцию.
Копия модели, изменение установленного пакета и скрытая новая схема запрещены.
