# PDF: обрезка вложенного объекта и порядок наложений

Владелец реализации — OpenDoc Formats. Приложение принимает официальный выпуск,
не разбирает native PDF, не исправляет команды отрисовки и не копирует backend.
Проверено 2026-10-10 на Formats 0.19.1 / Model 0.7.2, TextAlchemy 0.2.0rc2.
SHA-256 Formats `10923fd95441d0d88d618fd898bcfd00aa838a72528e5f13fe4c9086b01b7695`,
commit `00559a6376238a7395eece09d8a052f661dd2b3d`.

## Собственные случаи и два цикла

Все примеры — собственные цветные фигуры на странице 240×240 pt, без текста,
шрифтов и пользовательских материалов. Executor выполняет PDF → JSON-модель →
PDF дважды, не меняя исходник. Оба результата сравниваются с исходником, а не
только друг с другом. MuPDF и независимый Poppler рендерят при 72 dpi.

| Случай | Изменённых RGB-каналов: цикл 1 / 2 | Диагностика и бюджет 0 |
|---|---|---|
| Обрезанный Form XObject | 81312 / 81312 в обоих рендерерах | Нет сообщений; оба результата `success=true,lossless=true`; прежний файл заменён |
| Красный вектор → синее изображение → зелёный вектор | MuPDF 57600 / 57600, Poppler 58563 / 58563 | LOSS `pdf-raster-compositing`, `sections[0]`; строгий отказ сохраняет прежний файл |
| Красный вектор → полупрозрачный синий круг → зелёный вектор | MuPDF 29808 / 29808, Poppler 29784 / 29784 | Та же расположенная LOSS и безопасный строгий отказ |
| Красный вектор и отключённый голубой OCG | 0 / 0 в обоих рендерерах | OCG исчезает; первый цикл сообщает расположенную LOSS `pdf.catalog`, второй не сообщает потерь |

Визуальная сверка подтверждает: синий фон вложенного объекта выходит за обрезку
и закрывает красную рамку; растровое изображение/круг исчезают за восстановленным
красным вектором. У отключённого слоя совпал только исходный вид по умолчанию;
переключение слоёв не сохранено. Стабильный повреждённый второй цикл не доказывает
сохранность оригинала. Различия двух рендереров указаны отдельно.

## Минимальное воспроизведение обрезки

В PyMuPDF создать внешнюю страницу 240×240 и красный прямоугольник
`Rect(20,20,220,220)`. Во втором документе создать страницу того же размера,
синий фон `Rect(0,0,240,240)` и зелёный прямоугольник `Rect(70,70,170,170)`.
Вставить её вызовом
`outer.show_pdf_page(Rect(60,60,180,180), inner, 0, clip=Rect(50,50,190,190))`.
Сохранить внешний PDF и выполнить оба маршрута публичным executor приложения.
[Параметр clip](https://pymupdf.readthedocs.io/en/latest/page.html) задаёт выбранную
область исходной страницы; native QA используется только вне runtime приложения.

Собственные свидетельства: `.textalchemy/qa/pdf-compositing0191/`,
`evidence.json`, `poppler-evidence.json`, по каждому случаю исходник,
два JSON/PDF-результата и полные PNG обоих рендереров. Частные документы не входят
в воспроизведение и не передаются владельцу библиотеки.

## Контракт опубликованного исправления

Сохранить clipping, геометрию и порядок наложения либо сообщить расположенную
LOSS именно об упрощении этих свойств, либо отказать атомарно. Успешный результат
без зарегистрированных потерь не должен молча расширять обрезанный объект.
Бюджет 0 при невозможности сохранения оставляет прежний файл. Сохраняются
исходные байты, ограничения ресурсов, отмена и типизированная геометрия страниц.

Растровая замена сообщает утрату редактируемого вектора и структурированную связь
исходного объекта, замены и результата — запрос M6.3. Приложение не выводит связь
из текста сообщения. Для слоёв явно объявить сохранение переключения или
уплощение исходного вида. Повторная приёмка проверяет два цикла относительно
оригинала, feature/location и отказ без замены файла. PDF viewer корпуса остаётся
отдельной задачей M8.2. Реализация и её TODO принадлежат библиотеке.
