# Распознавание и извлечение

На странице «Распознать скан» выберите PDF или изображение, затем язык и способ обработки. Выбор файла ещё не запускает распознавание: нажмите «Получить текст», когда настройки готовы. Для изображения автоматически используется OCR; выбор способа обработки PDF скрывается. Рукописный режим и GPU раскрываются отдельно. Для PDF:

| Сценарий | Поведение |
|---|---|
| `fast` | Используется существующий текстовый слой, OCR не требуется |
| `structure` | Анализ текста и слияние с OCR; нужны компоненты распознавания |
| `scan` | Распознавание страниц как изображений |

```powershell
uv run textalchemy recognize source.pdf --scenario fast --output extracted.txt
uv run textalchemy recognize scan.pdf --scenario scan --backend tesseract --lang rus+eng --output recognized.docx
uv run textalchemy recognize notes.png --backend paddle --mode handwriting --gpu --output notes.txt
```

Для изображений OCR требуется всегда. Поддержаны Tesseract, EasyOCR и PaddleOCR; `auto` выбирает доступный backend. `--mode handwriting` — запрос режима рукописного текста, а не обещание точного распознавания. Перепроверьте имена, числа и формулы.

Результат команды `recognize` в DOCX — распознанный текст, не полная реконструкция расположения объектов. Для богатой PDF-модели используйте `extract.pdf_model` в конвейере.

На странице подготовки PDF к конвертации кнопка «Сохранить и проверить DOCX» сохраняет правки и выполняет пробный экспорт. Замечания также появляются перед скачиванием DOCX. Если сообщение содержит адрес блока, кнопка «Показать блок на странице…» открывает исходную страницу, выбирает блок и показывает его рамку. Например, предупреждение о замене PDF-вектора текстовой подписью ведёт к содержащему рисунок блоку. Для вложенного объекта показывается рамка блока-контейнера, а не точная область вложения. Общие сообщения без однозначного адреса остаются без перехода.

Адрес страницы после перехода содержит выбранный блок: при перезагрузке он восстанавливается вместе с нужной страницей, пока доступен черновик. Отчёт проверяет конкретную сохранённую версию; при локальных изменениях он скрывается до новой проверки. Переход помогает найти проблему, но не устраняет потерю автоматически. Отсутствие замечаний экспортёра не означает полную сохранность документа. Проверенный сценарий — векторный рисунок на второй странице PDF → предупреждение DOCX → исходный блок, в том числе после перестановки.

На странице подготовки PDF к конвертации для прямоугольной таблицы без объединённых ячеек доступна правка границ по строкам и столбцам. Выберите таблицу в списке, задайте первую/последнюю строку и столбец (нумерация с 1 по исходной таблице). Рамка и предварительный просмотр покажут выбранный диапазон. После «Сохранить правки» или «Сохранить и скачать» только эти ячейки входят в таблицу модели и DOCX; ячейки за границами исключаются из результата. Содержимое и свойства оставшихся ячеек сохраняются, другие блоки не меняются. Кнопка «Вся исходная таблица» возвращает полный диапазон, в том числе после сохранения и перезагрузки, пока не истёк срок хранения черновика. Возврат также нужно сохранить.

Это обрезка лишних крайних строк/столбцов по уже определённым границам ячеек. Произвольное рисование рамки, разделение и объединение ячеек, добавление нераспознанных областей, OCR таблиц и нерегулярные/объединённые ячейки не входят в этот сценарий. Если координаты ячеек отсутствуют или сетка неподдержана, панель границ не показывается. Проверенный пример — таблица 3×3 с линиями сетки, обрезка до 2×2 и полное восстановление. Векторные линии исходного PDF остаются самостоятельными объектами; исходное изображение и его линии при обрезке не перерисовываются.

Для PDF с текстовым слоем выберите файл на странице «Преобразовать» и нажмите «Подготовить PDF к конвертации». Выбранный файл откроется без повторной загрузки. Также есть ссылка со страницы распознавания. Это подготовка структуры будущего документа, а не редактирование PDF: исходный файл не изменяется. Настройки показываются для выбранной области: заголовки — для текста, границы — для таблицы. По умолчанию скачивается DOCX; JSON-модель доступна для автоматизации. Загрузите PDF, выберите страницу и нажмите нужный фрагмент непосредственно на изображении либо выберите его в списке. Области также доступны клавишей Tab; рамка показывает текущий выбор. Кнопки «Выше» и «Ниже» меняют последовательность блоков внутри выбранной страницы. Другие страницы и колонтитулы не меняются. «Сохранить правки» записывает изменения; адрес страницы позволяет восстановить их после перезагрузки. Срок хранения — один час после записи. При конфликте вкладок локальный список остаётся на экране; перед загрузкой сохранённого порядка зафиксируйте нужные перестановки.

«Сохранить и скачать» выдаёт JSON-модель или DOCX. При перестановке в JSON сохраняются исходные свойства, координаты и ресурсы импортированных блоков, меняется только их последовательность. DOCX следует новому порядку, но перестраивает вёрстку и может упрощать сложные объекты. Изображение исходного PDF служит ориентиром и не меняется после правок. Этот экран не выполняет OCR и не переносит блоки между страницами. Приёмка проведена на двухстраничном PDF без поворота страниц с текстом и встроенным изображением; сложные PDF требуют отдельной проверки.

Для текстового блока доступен выбор «Тип выбранного текста»: обычный абзац или заголовок уровней 1–3. Выберите тип, при необходимости переставьте блок, затем нажмите «Сохранить правки» или «Сохранить и скачать». Классификация сохраняется вместе с порядком и восстанавливается после перезагрузки. В DOCX заголовок получает соответствующий стиль и уровень структуры; обычный абзац — стиль Normal. Исходное оформление отдельных фрагментов текста сохраняется, поэтому внешний вид может отличаться от стандартного заголовка Word. Изображения, таблицы и формулы этим переключателем не переклассифицируются. «Исходная классификация PDF» обозначает отсутствие ручного выбора, а не гарантированную правильность автоматического определения.

Для изменения порядка текстовых абзацев в Web поставьте курсор в нужный абзац или выделите несколько, затем нажмите «Переместить выше» или «Переместить ниже». Каждая новая строка, включая пустую, считается отдельным абзацем; перенос по ширине поля границу не создаёт. Кнопки доступны с клавиатуры. Новый порядок сначала появляется в поле как несохранённая правка. Нажмите «Сохранить правки» или «Сохранить и скачать», чтобы записать его в модель и экспортировать. Это перестановка текста, без изменения геометрии исходной страницы.

В Web откройте «Распознавание», загрузите файл и исправьте текст в поле результата. «Сохранить правки» записывает текст в модель документа; «Сохранить и скачать» сначала сохраняет изменения, затем выдаёт TXT, DOCX, PDF или JSON-модель в выбранном формате. Пустые строки сохраняются как абзацы. Это редактор текста: исходное расположение объектов, таблицы и изображения в этот результат не входят.

После распознавания адрес страницы содержит ссылку на сохранённый текст. По ней можно вернуться к работе после перезагрузки страницы или сервера. По умолчанию текст хранится один час с последнего сохранения; несохранённый ввод остаётся только в открытой вкладке. При конфликте с другой вкладкой правки не перезаписываются: скопируйте свой текст, загрузите сохранённую версию и внесите изменения заново. Если OCR для изображения или скана недоступен, страница сообщает об ошибке и не создаёт фиктивный результат.

На странице «Извлечь содержимое» выберите PDF, DOCX, TXT или DjVu, затем результат — чистый текст или LaTeX из Word — и нажмите «Извлечь содержимое». Формат исходника определяется автоматически; ручной выбор раскрывается при необходимости. Готовый результат можно копировать или скачать как TXT/TeX. Смена настроек относится к следующему запуску и не меняет уже полученный результат. При отсутствии текста страница предлагает распознавание скана.

Оба экрана показывают редактор/просмотр только после получения результата. Имя исходника находится рядом с готовым текстом. Если обработка не удалась, выбранный файл, настройки и прежний текст остаются — исправьте причину и повторите запуск. Во время обработки нельзя отправить второй файл или изменить её параметры. В OCR порядок абзацев и загрузка сохранённой версии находятся в раскрываемом блоке «Порядок абзацев и сохранённая версия». При замене текста с несохранёнными правками нужно подтвердить их потерю; выбор нового файла сам по себе их не удаляет.

Команда `extract` предназначена для DOCX:

```powershell
uv run textalchemy extract source.docx extracted.txt --format text
uv run textalchemy extract source.docx extracted.tex --format latex
```

Для универсального извлечения PDF/PPTX/HTML/EPUB/TXT/DjVu используйте `extract.text` в конвейере. Для email есть `extract.emails` и сохранение через `render.emails.docx`/`render.emails.txt`: PDF обрабатывается по текстовому слою с OCR при необходимости.
