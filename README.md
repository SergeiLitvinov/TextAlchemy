# TextAlchemy

Локальная обработка научных и учебных документов: конвертация с отчётом о потерях, извлечение/OCR, библиотека и библиография, генерация по шаблонам и автоматизация. Доступны Web-интерфейс, CLI и Python API.

## Быстрый старт

Из каталога проекта, при установленных Python 3.11+ и `uv`:

```powershell
uv sync --extra web --extra docx --extra pdf --extra pptx --extra html --extra epub
uv run textalchemy web
```

Откройте [приложение](http://127.0.0.1:8000/). Полная установка с OCR и инструментами разработки: `uv sync --all-extras`; некоторые сценарии требуют внешних программ. Подробности — в [руководстве пользователя](docs/guide/index.md#установка-и-запуск).

Ограниченный PPTX-сценарий принят на двух презентациях в PowerPoint; HTML — на перечисленных примерах. Границы описаны в руководстве и справочниках.

Документация доступна также как сайт с поиском. Добавьте `--extra docs` к используемому набору зависимостей, затем выполните `uv run python -m tools.docs serve` и откройте [документацию](http://127.0.0.1:8001/). Проверка ссылок, актуальности справочников и исполняемых примеров: `uv run python -m tools.docs check`. [Установка и правила обновления](docs/development/documentation.md).

## Разработка

```powershell
uv sync --all-extras
uv run ruff check
uv run pytest tests/ -v --tb=short
uv run pytest tests/ --cov=textalchemy
```

При включённом покрытии действует порог 80%. Браузерные тесты требуют установленного Chromium (`uv run playwright install chromium`). Состав CI — в [workflow](.github/workflows/ci.yml); число тестов не фиксируется в README.
