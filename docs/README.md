## Разработка и происхождение примеров

[Система документации](development/documentation.md) описывает сборку сайта, поиск, автоматическую генерацию справочников и проверки CI. Локальный запуск: `uv run python -m tools.docs serve`; полная проверка документации: `uv run python -m tools.docs check`.

[AGENTS.md](../AGENTS.md), [стандарты кода](../CODING_STANDARDS.md), [корпус](../tests/corpus/README.md), [происхождение Office-fixtures](../tests/corpus/office/README.md) и [CI](../.github/workflows/ci.yml) предназначены для разработчиков и проверки свидетельств. Собственные golden-изображения выявляют регрессии, но не заменяют независимую приёмку в целевой программе.

При добавлении возможности обновляйте соответствующий раздел руководства, ограничения формата и статус одной вехи. Не добавляйте параллельный список обещаний в README или backlog.
