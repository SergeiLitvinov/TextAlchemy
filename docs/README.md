# Документация TextAlchemy

Начните с [руководства пользователя](guide/index.md). Оно описывает установку, действия в Web, CLI/API, форматы, ограничения и готовые примеры. [Корневой README](../README.md) — краткая точка входа, а не второй справочник.

## Где находится действующая информация

| Вопрос | Единственный основной источник |
|---|---|
| Как выполнить действие | Руководство; технические детали вынесены в главы форматов и Web/API |
| Какие файлы, определения, команды и маршруты есть в коде | Генерируемые страницы `reference/`; вручную их не исправляют |
| Что осталось сделать | `TODO.md`; списки старых ID и аудит не задают текущие статусы |
| Как расширять проект | `AGENTS.md` — контракты и рабочие команды; `CODING_STANDARDS.md` — стиль и архитектурные соглашения |
| Что и когда проверялось | Датированные отчёты `history/` и происхождение корпуса |

После аудита 2026-09-27 повторные карта файлов, контракт операций и содержание руководства заменены ссылками на эти источники. Отчёты приёмки, архивные снимки и карта миграции сохранены: их объединение с текущими инструкциями скрыло бы дату и границы свидетельств.

## Разработка и происхождение примеров

[Интерфейс шаблонизатора](development/templating.md) описывает работу с моделью OpenDoc и данными, подключение ресурсов и границу с файловыми адаптерами приложения.

[Система документации](development/documentation.md) описывает сборку сайта, поиск, автоматическую генерацию справочников и проверки CI. Локальный запуск: `uv run python -m tools.docs serve`; полная проверка документации: `uv run python -m tools.docs check`.

[AGENTS.md](../AGENTS.md), [стандарты кода](../CODING_STANDARDS.md), [корпус](../tests/corpus/README.md), [происхождение Office-fixtures](../tests/corpus/office/README.md) и [CI](../.github/workflows/ci.yml) предназначены для разработчиков и проверки свидетельств. Собственные golden-изображения выявляют регрессии, но не заменяют независимую приёмку в целевой программе.

При добавлении возможности обновляйте соответствующий раздел руководства, ограничения формата и статус одной вехи. Не добавляйте параллельный список обещаний в README или backlog.
