[Правила поддержки](../development/documentation.md).

Локальная проверка: 22 страницы собраны без предупреждений; проверены 33 примера команд, 273 записи миграции, конвейер и содержимое DOCX/HTML/PDF из шаблона. Пять тестов проверяют отказы при устаревшем справочнике, неверном аргументе, недопустимой ссылке и повреждённой карте миграции. В Chromium проверены поиск на русском, переходы, ширины 375/1280 px и обновление при правке исходного руководства. Исправлены переполнение таблиц и потеря запроса до готовности поискового индекса. Выполнение нового задания CI на GitHub этим локальным прогоном не подтверждается.

Сценарии выполненных возможностей собраны в [руководство пользователя](../guide/index.md), а фактические 27 операций — в отдельный справочник. README сокращён до запуска и навигации. Старый и короткий TODO, а также backlog объединены в M0–M8: выполненный базовый объём, ограниченная приёмка, оставшиеся результаты и условная приёмка на документах пользователя.

Все 273 отметки старого TODO сохранены в [карте миграции](todo-milestone-map.md), исходный архив не изменён. Повторная оценка всех исторических заявлений о качестве не заявляется. Исправлены устаревшие инструкции и ссылки; ограничения и результаты проверки примеров перечислены в [аудите](documentation-audit.md).

## 2026-09-13 — предупреждения HTML связаны с инспектором (первый срез U1)

Предупреждения CSS и ресурсов адресуют импортированный блок; одинаковые сообщения в разных блоках не объединяются. Идентификатор блока, сообщение и краткий фрагмент сохраняются через JSON модели и Web-задачи. Общие предупреждения открывают явно подписанную область «Весь документ». Проверены таблицы, разделённые контейнеры и отсутствующее изображение без подписи.

В Chromium при ширине 375 и 1280 px проверены переходы мышью и клавиатурой, фокус инспектора, отсутствие горизонтального переполнения и сброс при следующей конвертации. 307 целевых тестов HTML/Web/экспорта и два браузерных сценария прошли. Общая проверка обнаружила ошибку ранее добавленной регистрации extract.html_model: вместо строк типов были переданы классы, что ломало каталог операций Web. Исправлено с регрессией API.

Срез закрыт в границах [документации](../guide/formats.md#html): инспектор фрагмента, без редактора CSS и визуальной подсветки страниц. Артефакты локальны: `.textalchemy/acceptance/html-warning-navigation-final/`. Остаток U1 уточнён в backlog; следующий ограниченный результат — выборочный повтор неудачных файлов пакета (U3).

## 2026-09-13 — завершён первый срез статического HTML

Добавлены HTML → DocumentModel, базовый CSS cascade, упорядоченные блоки/списки/таблицы, ссылки, встроенные изображения/SVG/MathML и диагностика неподдержанного. Маршрут подключён к CLI, pipeline и Web. Компоненты bs4/tinycss2 остаются необязательными в extra html; lockfile обновлён.

Для обратного пути добавлены семантические HTML-списки, нативная нумерация и закладки DOCX, применение имеющегося MathML → OMML конвертера. Браузерная проверка обнаружила и помогла исправить плоское отображение формулы из-за XML-префикса. Корпус проверен через JSON-мутации, Web-загрузку, Chromium и выбранные правки в Word. [Полные границы и свидетельства](../guide/formats.md#html).

Следующий ограниченный результат взят из U1: переход от предупреждения HTML к месту в документе. Полное покрытие CSS не добавляется к завершённому срезу.

## 2026-09-13 — завершена ограниченная приёмка PPTX

Исправлены причины подтверждённых расхождений: цвет текста из ссылки на стиль фигуры с сохранением приоритета прямого форматирования; признак textbox; отсутствие ссылки на эффекты и явный effectRef=0; верхнее размещение при отсутствующем anchor. Уточнены LOSS-сообщения об оформлении таблицы и диаграммы.

Повторная проверка в PowerPoint на двух исходниках подтвердила открытие, число слайдов/объектов, заметки и сохранение правок текста, позиции, ячейки, кэша диаграммы и встроенной книги. Сравнены восемь изображений исходников и результатов; лишние рамки/тени и неверный цвет текста устранены. Прежнее наблюдение о смещении заголовка не воспроизвелось в новом экспорте; параметры текста в PowerPoint совпадают, отдельное исправление геометрии не заявляется.

Остаточные изменения темы таблицы, оформления диаграммы и градиента приняты как диагностируемые ограничения этого editable-среза. Полная визуальная точность и остальные возможности PPTX остаются вне приёмки. [Свидетельства и границы](pptx-acceptance.md).

732 теста tests/convert, tests/test_formats и tests/test_web_architecture.py прошли; Ruff без ошибок. Четыре новые регрессии проверяют источник цвета/его изменение и тип, размещение, отсутствие эффектов через два JSON/PPTX round-trip. Следующий результат активного TODO — богатый HTML-импорт.

## 2026-09-13 — упорядочивание по аудиту

Сохранён неизменённый [снимок прежнего TODO](todo-2026-09-13.md): 341 строка, 273 отметки, из них 45 открытых. Это исторический документ, а не действующий список задач. Закрытые формулировки в нём не означают повторной проверки всех возможностей; замечания об их достоверности перечислены в [аудите](todo-audit.md).

Повторы workspace, генератора, OCR-редактора, пакетных действий и архитектурных работ объединены. Из активного плана убраны история параметров и несколько конкурирующих P0/P1. Поддержка PPTX ограничена перечнем сценариев и отдельной [приёмкой](pptx-acceptance.md).

Исправления выявленных дефектов HTML-диаграмм:

- Множитель stdDev влияет на длину планок, включая нулевое значение. Исправлено описание текущего расчёта: делитель N; соответствие всей статистической семантики Office этим исправлением не заявляется.
- Неподдержанные log/power и неизвестные типы тренда пропускаются с LOSS chart-trendline и lossless=false. Они больше не рисуются линейными. Поддержанный тренд в том же наборе и основной ряд сохраняются.
- Добавлены численные проверки SVG-координат и полного отчёта HTML; 70 целевых тестов прошли (HTML writer, новые регрессии и PPTX forecast). Это не полный прогон проекта и не офисная приёмка.

Дополнительная регрессия: 626 тестов конвертеров и архитектуры Web прошли, Ruff по всему проекту без ошибок. Выполнена первая независимая проверка в PowerPoint: открытие, редактирование текста/позиции/таблицы/диаграммы и сохранение подтверждены; визуальные расхождения оставляют приёмку открытой. Подробности и следующая конечная очередь дефектов — в [приёмке PPTX](pptx-acceptance.md).

Правило множителя соответствует [описанию погрешностей Microsoft](https://support.microsoft.com/en-us/office/add-change-or-remove-error-bars-in-a-chart). Различия HTML и нативного PPTX описаны в документации формата.
