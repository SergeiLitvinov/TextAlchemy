# Приёмка базового HTML-импорта

Свидетельства 2026-09-13; текущие возможности описаны в [руководстве](../guide/formats.md#html).

## Проверенные результаты и границы

- Корпус: кириллица, заголовок/якорь, inline/internal CSS, !important, снятие strong через CSS, вложенные списки с началом 3, таблица с несколькими абзацами в ячейке, HTTP-ссылка и внутренняя ссылка, PNG data URI, SVG и дробь MathML, pre.
- JSON-мутации заголовка, ячейки и знаменателя доходят до HTML/DOCX. DOCX содержит нативную нумерацию с независимыми списками, OMML и внутренние ссылки на закладки. SVG/изображения остаются ресурсами модели; неподдержанные формулы имеют текстовый fallback с LOSS.
- Chromium: проверены нативное пространство имён MathML, наличие mfrac и изображение результата. Найденная ошибка префиксного XML в HTML исправлена в экспортёре: браузер видит math, а не неизвестный ns0:math с плоским текстом.
- Word 16.0: исходный DOCX открылся с одной формулой, одной таблицей и маркерами 3., •, 4.; изменения заголовка и ячейки сохранены в отдельную копию и проверены повторным чтением. Это проверка выбранных объектов, не полная визуальная приёмка Word/CSS. Закладки проверены отдельными тестами XML.
- 931 тест импортёров, конвертеров, pipeline, CLI и Web-каталога прошёл до заключительных исправлений; после них 72 целевых теста HTML/DOCX/Web прошли. Ruff без ошибок. Есть предупреждения устаревших API зависимостей и прежняя ошибка очистки pytest-current при коде завершения 0; тестовых ошибок нет.

Артефакты браузера и Word находятся локально в .textalchemy/acceptance/html-v1/ и игнорируются Git. Корпус и автоматические регрессии находятся в tests/corpus/scientific-html.html, tests/test_formats/test_html_model.py и tests/test_web_html.py.
