Изменить переменную шаблона

Переименуйте простую переменную во всех её вхождениях. Будет сохранена отдельная копия со своей схемой полей. Независимые простые условия и циклы сохраняются. Сложные выражения не переименовываются.

Латинские буквы, цифры и подчёркивание. Начните с буквы или подчёркивания.

Настроить условный абзац

Один абзац основного текста можно показывать по флажку. Сохраняется отдельная копия шаблона. Независимые циклы сохраняются; else и вложенные условия не создаются.

Латинские буквы, цифры и подчёркивание. Новое поле появится в данных документа; по умолчанию выключено.

Повторять абзац по списку

Выберите простой абзац основного текста и переменную, которая будет получать очередное значение списка. Пустой список убирает абзац. Для таблиц используйте действие ниже. Другие независимые конструкции сохраняются; вложенные циклы не создаются.

Новое поле появится в данных документа. Добавляйте значения по строкам и меняйте их порядок кнопками. Прежние поля сохраняются.

Повторять строку таблицы

Выберите строку без объединённых ячеек и переменную для очередного значения списка. Остальные ячейки повторятся вместе с ней; пустой список убирает выбранную строку.

Добавляйте значения по строкам в данных документа. Поддержаны простые строки таблиц основного текста; вложенные таблицы и управляющие конструкции не поддерживаются.

Редактор поддерживает простые конструкции. Условия, циклы и вставки можно сочетать в разных местах одной копии; вложенные конструкции не создаются.
