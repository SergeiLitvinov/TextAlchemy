Сохранённые данные и черновик

Черновик сохраняется в этой вкладке отдельно для каждого шаблона. После перезагрузки открывается новая форма; восстановление прежних полей и изображений выполняется только по кнопке. Это временное хранение: не используйте его как архив после закрытия вкладки.

Именованные наборы данных

Хранятся на сервере без срока истечения. Доступны во всех вкладках этого приложения. Данные проверяются перед генерацией.
