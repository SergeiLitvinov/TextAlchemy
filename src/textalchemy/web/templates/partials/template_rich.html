Изображение, формула, источники или ссылка

Выберите обычный абзац основного документа. Его содержимое заменится выбранным объектом. Метка сохраняет текст абзаца и позволяет ссылаться на него.

Для ссылки укажите имя ранее созданной метки, например sec:conclusion. Имя поля — латиницей без пробелов. Список источников использует поле bibliography; источники можно добавлять текстовыми строками.

Формула принимает LaTeX или MathML. Поддержанный MathML создаёт редактируемую формулу Word; LaTeX может выводиться текстом. Проверьте заполненный результат перед скачиванием.
